# 问题追踪表

所有 BUG / 异常 / 待办的**总表**。重大问题的分析过程另建 `问题-NNN_标题.md` 放在本目录，与下表互相链接。

| 编号 | 发现日期 | 现象 | 影响范围 | 严重度 | 责任人 | 状态 | 详情 |
|---|---|---|---|---|---|---|---|
| 问题-001 | YYYYMMDD | | 硬件 / 固件 / 结构 / 工艺 | 高 / 中 / 低 | | 待分析 | [问题-001_标题.md](问题-001_标题.md) |

## 状态定义

| 状态 | 含义 |
|---|---|
| 待分析 | 已记录，还没定位原因 |
| 处理中 | 已定位，正在改 |
| 待验证 | 已改，等测试/客户确认 |
| 已解决 | 验证通过，写上解决方案与验证日期 |
| 挂起 | 暂不处理，必须写明挂起原因和重启条件 |

> 原则：**谁发现谁登记，登记就不要只记在脑子里或聊天记录里。**
> 严重度评「高」的问题，同步在 `06_management/开发日志/` 当月文件里记一行。
